# Myosotis

취향과 계절을 기준으로 향수를 둘러보는 정적 웹사이트입니다.

[사이트 보기](https://kimyeounmu2000-glitch.github.io/Myosotis/)

## 사용자 관점에서 개선한 내용

처음 방문한 사람이 사이트 목적과 첫 행동을 이해할 수 있는지 AI에 검토를 요청하고, 피드백을 바탕으로 수정 방향을 정했습니다. 이미지 잘림, 간격, 메뉴 위치를 확인하면서 기존 디자인 의도가 유지되도록 조정 요청했습니다.

- 첫 화면에 “취향과 계절로 둘러보는 향수 가이드”를 추가했습니다.
- 버튼을 “좋아하는 느낌으로 둘러보기”로 안내합니다. 정해진 상세 페이지로 이동하는 탐색 기능이며 개인화 알고리즘은 아닙니다.
- 사용자는 문제 발견과 수정 방향 결정에 참여했습니다. 이 대화에서 진행한 코드 수정·배포는 AI가 수행했습니다. 최초 코드와 그 외 변경의 직접 작성 범위는 별도 확인이 필요합니다.

## 기술과 사용 목적

HTML로 페이지 구조를 구성하고, CSS Grid·Flexbox와 미디어쿼리로 카드 및 상세 영역을 배치합니다. 이미지 영역은 aspect-ratio와 object-fit으로 관리합니다. 메뉴는 외부 라이브러리 없이 JavaScript로 제어하며, 기존 상세 페이지의 Bootstrap 구성은 유지합니다. GitHub Pages로 배포합니다.

## 문제 해결

### 메뉴의 의미와 동작

기존 MENU는 href="#" 링크에서 클래스만 전환했습니다. 이동이 아닌 여닫기 기능에 맞춰 button으로 바꾸고 aria-expanded, aria-controls 및 hidden 상태를 함께 관리합니다. Enter·Space로 여닫기, Esc로 닫고 버튼으로 포커스 복귀, 바깥 클릭과 메뉴 밖 포커스 이동 시 닫기를 구현했습니다. 기능이 없는 언어 항목은 제거했습니다.

### 모바일 가독성

모바일 메뉴와 푸터 글자가 지나치게 작아지는 규칙이 있었습니다. 공유 메뉴 글자와 클릭 영역을 명시하고, 모바일 본문·푸터를 읽을 수 있는 크기로 조정했습니다. 좁은 화면에서 긴 카드 이름이 잘리지 않도록 줄바꿈과 카드 열 수를 조정했습니다.

### 카드 이미지와 내용

목록의 3:4 이미지 영역을 유지하고 긴 제목·브랜드명이 행 높이에 반영되도록 구성했습니다. cover는 일부를 자를 수 있고 contain은 여백이 생길 수 있으므로 두 표시 방식을 구분합니다. 기존 상세 이미지 비중과 계절 hover 효과는 유지했습니다.

### 배포 경로 오류

HTML의 파일 참조와 실제 css·img 폴더 위치가 달라 CSS와 이미지가 빠졌던 문제가 있었습니다. 사용자가 깨진 화면을 제공했고 AI가 경로와 대소문자를 대조해 수정했습니다. 이 사례를 사용자 혼자 진단·구현한 성과로 표현하지 않습니다.

## 검증 기록

수정본에서 31개 완전한 HTML 페이지의 로컬 파일 참조, 메뉴 버튼 속성, 중복 ID를 검사했습니다. 메인·전체 목록·봄 목록·기존 상세·추가 상세의 5개 대표 페이지는 375·768·1024·1440px에서 가로 넘침 여부를 확인했습니다. 메뉴의 Enter·Space 열기와 Esc 닫기도 브라우저에서 확인했습니다.

이 검사는 모든 브라우저·보조기술의 접근성 적합성을 보증하지 않습니다. 기존 HTML 조각인 dustmq.html은 완전한 페이지 검사에서 제외했습니다.
